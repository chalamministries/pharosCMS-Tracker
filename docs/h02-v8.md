# H02 V8 positions

H02 TCP 5013 accepts V8 position reports as well as V1/V4. The common fields
contain the transmitted device ID, UTC time/date, validity, coordinates, speed
(knots converted to km/h), course and status word. Longitude may omit leading
zeroes, including values below one degree. TCP buffering remains handled by the
existing gateway: an incomplete frame consumes no bytes, and concatenated
frames are consumed one at a time.

The confirmed SinoTrack V8 extension layout is country/network codes, area/cell
IDs, satellites, signal strength (0–31), battery voltage in tenths of a volt,
then battery percentage (0–100). The decoder exposes named sensors and the
native satellite count while retaining `h02_io1` through `h02_io8`. Optional
missing or invalid values remain absent rather than becoming zero. Network
codes preserve leading zeroes. The older V1 optional sensor layout is unchanged.

For V8, status bit 10 is ignition (1=on). Alarm bits 0, 1, 2, 18 and 19 are
active-low; `FFFFFBFF` therefore means ignition off and no alarms. Bit 1 is an
alarm indicator, not charging: the decoder does not infer a charging state.
GPS validity comes from the A/V field. Raw status and historical data remain
unchanged. No relay, device-programming or port changes are involved.

## Per-device map display

Open the dashboard's top-right gear, then **Management > Devices > Edit > General**.
**Battery level field (%)** selects the sensor that already reports 0–100 percent.
That source is displayed with a percent sign in the map popup and left-hand tile.
It is saved only for that device, under `config.sensors.battery_level`. Recognized
native `battery_level` and `battery_pct` sensors also work on the map and tiles without an
override. A voltage reading is never automatically converted to a percentage.
Missing or invalid values show **Unavailable**, and zero remains a valid value.

**IO and sensor labels** saves per-device labels under `config.sensor_labels`.
Blank labels use the automatic name. Map popup labels and their history links
use the configured name while keeping the original sensor key for querying
history. Neither labels nor the battery source rewrite raw telemetry or past
records. These display settings do not configure alerts, scale raw values, or
decode status bits. In particular, renaming a charging field does not establish
that its status-bit interpretation is correct.

Reference: [Traccar H02 decoder tests](https://github.com/traccar/traccar/blob/master/src/test/java/org/traccar/protocol/H02ProtocolDecoderTest.java)
include V8 packets with this common layout and unpadded longitude.
